# 空间校对 · 通用 3D 编辑器

面向 AI 生成空间模型的校正与确认工具。支持从平面图生成多层空间，也支持直接创建空白项目或导入项目 JSON；识别后可以继续编辑墙体、门窗、空间、家具、楼板、吊顶和屋面，并通过俯视、剖面、楼层爆炸和第一人称漫游检查结果。

## 主要功能

- 0.5 m 网格吸附、墙端点/中点吸附、墙体自动转角覆盖，以及墙高和墙厚编辑。
- 门窗直接点选、尺寸修改、铰链与开启方向设置、删除后自动补墙。
- 自动空间分区、面积与周长分析、半透明空间体块和独立空间命名。
- 多楼层叠放、爆炸、单层查看，楼板、吊顶、屋面、雨棚和排水构件。
- 家具目录、同类替换、移动、旋转、缩放、房间边界限制和碰撞检查。
- 10 种材质预设，以及颜色、粗糙度、金属度和透明度编辑。
- 原始图纸对照、项目自动保存、JSON 导入导出和室内漫游。
- `legacy/` 中包含完整的四层别墅模型演示。

## 本地运行

在本目录运行 `npm start`，打开 `http://127.0.0.1:8095/`。Windows 也可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1`；脚本会检查服务是否已启动，避免重复占用端口。需要 Node.js 18 或更新版本。

AI 图纸识别使用 Inferera / AIHubMix 的 Responses API。将 `INFERERA_API_KEY=你的密钥` 写入本目录的 `.env.local`，或在启动服务前设置同名环境变量；可选 `INFERERA_PLAN_MODEL`，默认 `gpt-6-sol`。`.env.local` 不会由网页服务器提供，也已加入 `.gitignore`。不要把密钥写入 `app.js` 或提交到公开仓库。

识别规则详见 [识别约束词.md](./识别约束词.md)。服务依次请求外轮廓及外墙、内墙及门窗、封闭空间三个识别阶段，并在上传页显示当前阶段。输入建筑基准宽度和深度能减少比例偏差；服务会按模型基准框换算坐标，将外墙轮廓、楼板外轮廓与房间分区分开保存。上传多层时后续楼层的外轮廓会参考首层图纸的共同轴网。

起始页支持上传 1–10 张 PNG、JPEG、WebP 图纸，一张对应一层。识别结果包含空间、墙、门窗和图纸中明确存在的家具；未识别出家具时保留空家具列表，空间以“未命名1、未命名2…”编号，可以在编辑器里改名。AI 生成的几何仍需人工核对。

编辑器中的外墙轮廓锁定，外墙上的门窗仍可编辑；图纸填充内墙必须建模，可拆内墙可以移动、伸缩或删除。每个空间都可以显示为半透明彩色体块；关闭“墙面”或点击“只看空间”可核对空间比例和尺寸。旧项目 JSON 仍可导入，旧外墙按楼板轮廓尽量识别并锁定。

可以不调用 AI，直接建空白空间，或导入之前导出的项目 JSON。项目会自动保存于本机浏览器，也可导出 JSON 备份。原有别墅演示从 `/legacy/` 打开，新编辑器不会修改该演示。

## GitHub Pages

仓库包含自动部署工作流。Pages 静态版本支持空白项目、JSON 导入导出、完整模型编辑、家具目录和别墅演示。AI 图纸识别需要服务端保存 API 密钥，因此只在运行 `server.mjs` 或部署等价后端时启用；不要把 API 密钥写入前端文件或提交到公开仓库。

运行 `npm test` 可以检查项目数据结构、识别约束、楼层坐标、家具目录和墙体边界规则。
